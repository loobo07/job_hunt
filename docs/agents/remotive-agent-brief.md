# Remotive Documentation Agent Brief

## Mission

Produce and maintain source-specific documentation for Remotive ingestion.

## Inputs

- Intended Remotive remote jobs API source
- [Job Board Ingestion Requirements](../requirements/job-board-ingestion-requirements.md)
- [DevOps and Infra Architecture](../architecture/devops-infra-architecture.md)

## Outputs

- UML class diagram for the Remotive ingestion adapter
- API sequence diagram for the ingestion flow
- Remotive ingestion design notes
- Validation rules and failure handling notes

## Scope

- Remote-first job ingestion
- Remote-type ranking signals
- Salary and location handling when available
- Optional source availability

## Acceptance Criteria

- The doc explains that Remotive is a remote biasing source.
- The doc explains how remote type is used in ranking.
- The doc explains how the system behaves when the source is unavailable.
