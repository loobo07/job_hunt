# Source Documentation Agents

This folder defines one documentation agent per intended ingestion source. Each agent is responsible for producing source-specific documentation that matches the shared requirements, canonical schema, and infra model in the main docs.

Shared references:

- [Job Board Ingestion Requirements](../requirements/job-board-ingestion-requirements.md)
- [DevOps and Infra Architecture](../architecture/devops-infra-architecture.md)
- [Job Posting Alignment Application Plan](../job-posting-alignment-plan.md)

Agent output pattern:

1. Source summary
2. Canonical data mapping
3. UML class diagram
4. API sequence diagram
5. Ingestion design notes
6. Validation and failure handling
