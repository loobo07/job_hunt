# Diagram Artifacts

This directory is the target location for rendered diagram exports when the Mermaid source blocks are converted to SVG or PNG.

## Naming Convention

- `adzuna-ingestion-design-1.svg`
- `adzuna-ingestion-design-1.png`
- `usajobs-ingestion-design-1.svg`
- `usajobs-ingestion-design-1.png`

Use the source document stem plus the Mermaid block index so each artifact is traceable back to its definition.
